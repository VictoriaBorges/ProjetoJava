# PetShop E-commerce

> Sistema de gerenciamento de produtos para PetShop, com funcionalidades como cadastro, listagem, busca, atualização e remoção de produtos.


## Índice

- [Funcionalidades](#funcionalidades)

## Sobre

Este é um sistema de **E-commerce para PetShop**, onde é possível gerenciar produtos de petshop, com as seguintes funcionalidades:

- **Cadastro de Produtos**
- **Listagem de Produtos**
- **Busca de Produtos**
- **Atualização de Produtos**
- **Remoção de Produtos**

## Funcionalidades

- **Cadastrar Produto**: Permite adicionar novos produtos ao sistema.
- **Listar Produtos**: Exibe todos os produtos cadastrados no sistema.
- **Buscar Produto**: Permite buscar produtos pelo nome.
- **Atualizar Produto**: Permite atualizar as informações de um produto existente.
- **Remover Produto**: Remove um produto do sistema.

## Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- **Java**: Linguagem principal utilizada para o desenvolvimento do sistema.
- **Scanner**: Utilizado para ler as entradas do usuário.
- **InputMismatchException**: Usado para tratamento de erros de entrada inválida.
